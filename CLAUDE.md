# CLAUDE.md: Pkmn

Kotlin/Gradle multi-module game: `engine` (battle rules), `core` (game state, saves),
`tools` (content pipeline and audits), `desktop` (LWJGL3), `android`.
Current state and every measured number: `STATUS.md`. Mechanics detail: `docs/`.

## Rules
- `assets/` is generated by the `:tools` content tasks. Change the sources (`data-src/`,
  `world/`), regenerate, and commit the result; CI fails if `git diff -- assets/` is non-empty.
- Numbers in `STATUS.md` must come from a command; update them only by rerunning it.

## Model routing for this repo
- Opus: battle-engine mechanics with subtle interactions, save-format migrations.
- Sonnet: features, maps/scripts, UI, tests, tools.
- Haiku (`explorer`): finding data or scripts, summarizing audit reports.

## Verification (same as CI)
1. Content gates: `./gradlew :tools:compileMaps :tools:checkProgression :tools:validateContent :tools:buildAssetManifest`
   then `git diff --exit-code -- assets/`
2. Tests: `./gradlew :engine:test :core:test :tools:test`
3. Android build: `./gradlew :android:assembleDebug` (`:android:bundleRelease` before a release)
4. UI changes: check on the emulator with the Android QA plugin and attach a screenshot.
