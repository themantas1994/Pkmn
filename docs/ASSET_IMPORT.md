# Asset import, attribution and the asset manifest

## Why official artwork is not bundled

Pokémon sprites, models, music and other official artwork are © Nintendo / Creatures / GAME FREAK.
Third parties may not redistribute them. This repository and every build it ships may therefore contain only:

- original or openly licensed art, listed in `assets/ATTRIBUTION.json` with `"redistributable": true`;
- generated data (`assets/data/*.json`, built from Pokémon Showdown (MIT) and PokeAPI (BSD-3-Clause) data; see
  `assets/data/manifest.json`).

If you want official sprites in **your own personal build**, import them locally. They go into `assets-local/`.
That directory is git-ignored (see `.gitignore`), so it is never committed. The tools never copy it into `assets/`.

## Directory contract

```
assets/                          bundled, redistributable (committed)
  ATTRIBUTION.json               source/license for every asset (schema below)
  manifest/assets.json           generated by :tools:buildAssetManifest
  sprites/pokemon/<kind>/<speciesId>.png   (optional, only openly licensed art)
assets-local/                    local only, git-ignored, NEVER redistributed
  sprites/pokemon/<kind>/<speciesId>.png
  sprites/IMPORT_LOG.json        provenance of every imported file
  manifest/assets.json           generated by :tools:buildAssetManifest (same schema)
```

- `<kind>` is one of `front`, `back`, `front-shiny`, `back-shiny`, `icon`.
- `<speciesId>` is **our** species id, the same as in `assets/data/species.json` (Showdown-style, e.g. `bulbasaur`,
  `charizardmegax`, `raichualola`, `urshifurapidstrikegmax`).

### Runtime lookup (implemented by the core/Android side)

| Platform | Local override directory | Notes |
|---|---|---|
| Desktop | `assets-local/` next to `assets/` (the working directory) | Used automatically when it exists. |
| Android | app-internal storage `imported/` (`Context.getFilesDir()/imported/`) | Same layout as `assets-local/`, e.g. `imported/sprites/pokemon/front/pikachu.png`. Filled by an in-app import of a directory or zip with this layout. |
| Android (personal APK) | `-Ppkmn.bundleLocalAssets=true` | Copies `assets-local/` into the APK so the sprites ship inside it. **Use this only for builds you install yourself. Never publish such an APK.** |

Lookup order for one sprite: local override → bundled `assets/` → the same kind for the species' `baseSpecies` →
a placeholder. A missing file is never an error at runtime. The import log lists sprites that PokeAPI does not provide.

## Importing sprites from PokeAPI

```
./gradlew :tools:importSprites                                   # everything (~1379 species entries × 5 kinds)
./gradlew :tools:importSprites -Pargs="--only=1-151"             # National Dex range(s), e.g. --only=1-151,252-386
./gradlew :tools:importSprites -Pargs="--only=1-30 --forms=false --kinds=front,back"
./gradlew :tools:importSprites -Pargs="--force"                  # re-download files that already exist
```

| Option | Default | Meaning |
|---|---|---|
| `--only=<ranges>` | all | National Dex numbers, comma-separated ranges. Forms follow their species' number. |
| `--forms=<bool>` | `true` | Also import alternate forms, Megas, G-Max, regional forms and so on. |
| `--kinds=<list>` | all five | Any of `front,back,front-shiny,back-shiny,icon`. |
| `--force` | off | Overwrite existing files. Without it, existing files are skipped and kept in the log. |
| `--jobs=<n>` | 8 | Number of parallel downloads (1–32). |
| `--retries=<n>` | 3 | Retries for network errors, HTTP 429 and HTTP 5xx, with exponential backoff. HTTP 404 means "not available" and is not retried. |
| `--from=<dir or zip>` | – | Import a user-supplied directory or zip instead of downloading (see below). |
| `--base-url=<url>` | PokeAPI sprites | Use a different mirror with the same layout. |

Sources, from `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/`:

| kind | URL (first match wins) |
|---|---|
| front | `{stem}.png` |
| back | `back/{stem}.png` |
| front-shiny | `shiny/{stem}.png` |
| back-shiny | `back/shiny/{stem}.png` |
| icon | `versions/generation-viii/icons/{stem}.png`, then `versions/generation-vii/icons/{stem}.png` |

Every download is checked to be a PNG. Anything else counts as a failure.

### Species → PokeAPI mapping

`{stem}` is the PokeAPI file name. `SpriteMapping` (tools) works it out in this order:

1. A short explicit alias table, for cases where the names share nothing or the default form differs.
   Examples: `rockruffdusk` → `rockruff-own-tempo`; `maushold` (Showdown: Family of Three) → `maushold-family-of-three`.
2. Base species: the National Dex number (`bulbasaur` → `1`).
3. An exact match of our id against the `toId(identifier)` column of `data-src/pokeapi/pokemon.csv`
   (`charizardmegax` → `charizard-mega-x` → `10034`).
4. An exact match against `data-src/pokeapi/pokemon_forms.csv`. A non-default form uses `{pokemon_id}-{form_identifier}`
   (`arceusfire` → `493-fire`).
5. A token match: the tokens of our forme name must all appear in a PokeAPI identifier of the same species.
   Fewest extra tokens wins, then the lowest id (`pikachualola` → `pikachu-alola-cap`; `meowsticf` → `meowstic-female`).

Anything still unmatched is listed under `unmapped` in the log and never guessed. Currently that is only Ogerpon's four
Terastallized masks, which PokeAPI does not provide. Kinds that PokeAPI lacks are listed under `missing`. For example,
Gen IX species (#906+) have no menu icons. The Legends: Z-A Megas we checked (Mega Raichu X/Y, Mega Greninja) have none either.

### Importing your own files (`--from`)

```
./gradlew :tools:importSprites -Pargs="--from=/path/to/my-sprites.zip"
./gradlew :tools:importSprites -Pargs="--from=/path/to/dir --kinds=front,back --force"
```

The directory or zip must contain `<kind>/<speciesId>.png` files. Any leading folders are ignored, so
`pack/sprites/pokemon/front/pikachu.png` works. Files with an unknown species id or with non-PNG content are reported
as failures. The tool writes files only to paths it builds from the species id, so a zip entry cannot write anywhere else.

  "lastRun": "2026-10-13T13:05:24Z",

## `assets/ATTRIBUTION.json` schema

```json
{
  "version": 1,
  "entries": [
    { "pathGlob": "assets/tiles/**", "source": "https://…", "license": "CC0-1.0", "author": "Name",
      "redistributable": true, "status": "placeholder" }
  ]
}
```

- `pathGlob` is a `java.nio` glob relative to the repository root. `**` crosses directories and `*` does not.
  When several entries match a file, the **last** one wins, so put specific entries after general ones.
- `pathGlob`, `source`, `license`, `author` and `redistributable` (a boolean) are required.
- `status` is optional: `placeholder`, `wip`, `final`, `generated` or `local-import`.
  It is copied into the manifest as the implementation status.
- A file under `assets/` with no matching entry, or matching only `redistributable: false`, is an **error**.
  An unmatched file under `assets-local/` is a warning and is treated as non-redistributable.

## Asset manifest (`./gradlew :tools:buildAssetManifest`)

The tool scans `assets/`, skipping `assets/data/`, the generated `assets/manifest/` and `ATTRIBUTION.json`. It also
scans `assets-local/` if that exists. It writes:

- `assets/manifest/assets.json`: bundled assets only, so the committed manifest never names local files.
- `assets-local/manifest/assets.json`: local assets, in the same schema.
- `reports/asset-validation.json`: errors and warnings. The task fails if there are any errors.

Each entry has: `id` (path without extension; a sheet descriptor gets `<stem>.sheet`), `path`, `format`, `sizeBytes`,
`width`/`height` (images, read with `javax.imageio`), `category`, `frames` (when a sheet descriptor declares them),
`source`, `license`, `author`, `redistributable` and `status`.

Category comes from the path: `sprites/pokemon/` → `pokemon-sprite`. Other folder names map like this:
`tiles|tilesets` → `tile`, `characters|npcs|player|overworld` → `character`, `ui|gui|hud` → `ui`,
`fonts` or `.ttf/.otf/.fnt` → `font`, `audio|music|sfx` or `.ogg/.wav/.mp3` → `audio`, `maps` or `.tmx/.tsx` → `map`.
Everything else is `other`.

Checks:

| Check | Severity |
|---|---|
| Unsupported format (supported: png, json, atlas, fnt, ttf, otf, ogg, wav, mp3, tmx, tsx, txt, csv, glsl, vert, frag) | error |
| Zero-size file, unreadable PNG | error |
| PNG width/height not a multiple of 8: tile, character or ui art in `assets/` | error |
| PNG width/height not a multiple of 8: anything else (e.g. the 68×56 Gen VIII icons) | warning |
| Sheet descriptor referencing frames that do not exist (frameCount larger than the grid, missing frame files, animation indices out of range) | error |
| Pokémon sprite with an unknown kind or a file name that is not a species id | error |
| Missing attribution / non-redistributable file under `assets/` | error |
| Duplicate asset id | error |

### Sprite sheet descriptor

The descriptor is a sibling `<name>.json` next to `<name>.png`. A standalone `.json` with a `frames` list is also checked.

```json
{ "frameWidth": 16, "frameHeight": 16, "frameCount": 12,
  "animations": { "walk_down": { "frames": [0, 1, 2, 1], "fps": 8 }, "idle": [0] } }
```

Alternatively, `"frames": ["walk0.png", "walk1.png"]` lists one file per frame, with paths relative to the descriptor.
